# 語言規範 (Language Rules)

應始終使用**台灣正體中文**（Traditional Chinese,
Taiwan）與使用者進行溝通，並在撰寫文件、註解及提交訊息時遵循此規範。

## 避免中國用語

正體中文不只是字體，用詞也必須是台灣慣用語。以下為常見誤用，應主動替換：

| 中國用語 | 台灣用語 |
|----------|----------|
| 大概率 / 小概率 | 高機率 / 低機率 |
| 質量（品質意義時） | 品質 |
| 信息 | 資訊 |
| 網絡 | 網路 |
| 軟件 / 硬件 | 軟體 / 硬體 |
| 服務器 | 伺服器 |
| 數據庫 | 資料庫 |
| 屏幕 | 螢幕 |
| 視頻 | 影片 |
| 默認 | 預設 |
| 通過（作「藉由」解時） | 透過 |
| 用戶 | 使用者 |
| 項目（作 project 解時） | 專案 |

此表為示例而非窮舉；遇到不確定的詞彙，優先選擇台灣技術社群的慣用說法。
